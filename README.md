# 天台疾行 / Rooftop Dash

2D 横版像素风**自动跑酷 + 动作**原型（Unity 2022.3 LTS）。玩家在赛博朋克夜景的屋顶间自动向前奔跑，靠**跳跃、挥剑、疾行印记冲刺**跨越间隙、清理敌人，用金币在路边的商店买三选一增益。

> 当前状态：**可玩原型（P0）**，一关完整关卡，约 1.5 分钟。

## 玩法

| 操作 | 按键 |
|---|---|
| 跳跃 | `空格` / `↑` |
| 挥剑 | `J` |
| 冲刺 | 踩到**疾行印记**自动触发（关卡里 20+ 个） |
| 暂停 | `Esc` |
| 重开 | `R` |
| 选增益 / 购买 | `1` `2` `3` 或点击卡片 |

- **冲刺是核心**：`2.6×` 倍速、0.55s，期间可补一次跳跃（不打断冲刺）、撞怪造成伤害、且无敌。关卡里有大量**只有冲刺才过得去**的深渊（20~24u）。
- **剑**：待机插在背后 → 出手时过肩拔出 → 从头顶斜劈到身前下方（136° 扫角）→ 收回背上。范围增益会让剑肉眼可见地变长。
- **敌人**：巡逻型 + 追踪型；踩头可以弹起并造成伤害且不掉血。
- **商店**：路上的招牌，花金币买三选一增益（价格可配）。

## 运行

1. Unity **2022.3.62f3c1**（同系列 2022.3.x 均可）打开项目
2. 打开 `Assets/_Project/Scenes/Level_01.unity`
3. Play

> Game 视图建议设 **16:9**（1920×1080 或 1280×720），PPU16 + 正交尺寸 16.875 在这个比例下才是 1:1 像素。

## 工程结构

```
Assets/_Project/
├─ Art/            素材（ArtLibrary.asset 统一引用，不走 Resources）
│  ├─ Sprites/       Player / Enemy / Tiles / Props / Fx / Bg / UI
│  └─ Audio/         程序合成的 SFX 与 BGM
├─ Prefabs/        Player / Drone / Turret / RoofPlatform / FloatPlatform / DashMarker / Portal
├─ Scenes/         Level_01.unity（关卡已烘焙成场景对象，运行时零生成）
└─ Scripts/
   ├─ Core/        GameManager / GameBootstrap / 输入 / 相机 / 时间缩放 / 像素素材总表
   ├─ Player/      自动奔跑 / 跳跃 / 挥剑 / 剑的动作 / 生命 / 冲刺 / 视觉状态机
   ├─ Enemies/     敌人行为 / 血量 / 视觉
   ├─ Level/       平台 / 印记 / 终点 / 距离节点 / 商店 / 金币 / 视差背景 / 天空事件
   ├─ Upgrades/    增益定义与管理
   ├─ UI/          像素风 HUD、三选一、商店、暂停/失败/通关面板
   ├─ Audio/       音频管理
   └─ Editor/      素材导入规则、关卡烘焙工具（Tools/天台疾行）
```

**改关卡不用改代码**：选中 `Level` 下的平台改 `PlatformPiece.width`，碰撞体和贴图会自动同步；拖拽印记/终点后节点距离会在运行时自动重算。

## 素材与音效

- 美术：**Warped City** by [ansimuz](https://ansimuz.itch.io)（CC0），地表瓦片、夜空、剑/金币/商店图标为按包内配色自绘。
- 音效与 BGM：numpy 程序合成，无版权风险。
